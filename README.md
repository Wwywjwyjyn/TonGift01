# بازار گیفت تلگرام — نسخه ۳.۰ (مارکت رسمی تلگرام با MTProto)

اپ اندروید Flutter برای خرید/فروش گیفت‌های استارزی **مارکت اصلی تلگرام** با API ID/Hash خودت + بخش TON (اجاره/کالکشن/استارز Fragment).
**هیچ داده دمویی وجود ندارد** — همه‌چیز از API واقعی می‌آید.

## تازه‌های نسخه ۳.۰ — مارکت رسمی تلگرام داخل اپ

با API ID/API Hash خودت (از my.telegram.org) و **لاگین اکانت تلگرام داخل اپ**، کل مارکت اصلی تلگرام می‌آید داخل:

- **بازار (تب اول)** — سوییچ «گیفت تلگرام | NFT تون»:
  - کاتالوگ کامل گیفت‌های استارزی (`payments.getStarGifts`) با عکس واقعی، قیمت نو، موجودی و کف قیمت دست‌دوم
  - با زدن روی هر گیفت: صفحه‌ی فروشندگان (`payments.getResaleStarGifts`) با مرتب‌سازی ارزان‌ترین/شماره/جدید
  - **خرید با استارز** از فروشندگان (`inputInvoiceStarGiftResale` + `sendStarsForm`) یا خرید گیفت نو و هدیه به خودت/دوستانت
- **انبار** — سوییچ «تلگرام | تون»: گیفت‌های واقعی اکانت تلگرامت (حتی ذخیره‌نشده‌ها) با «از طرف کی»
  - **فروش‌گذاری با قیمت استارز** (`payments.updateStarGiftPrice`)، تغییر قیمت، حذف از فروش (قیمت ۰)
  - **انتقال/هدیه به یوزرنیم** (`payments.transferStarGift`) + نمایش هزینه انتقال
  - **آپگرید به گیفت یکتا** (`payments.upgradeStarGift`)، «مشاهده در تلگرام» با لینک t.me/nft
- **ورود تلگرام ۳ مرحله‌ای**: شماره ← کد ← رمز دومرحله‌ای (SRP). نشست روی بک‌اند خودت در `tg_sessions.json` (رمزنگاری AES-256-CBC با `TG_SESSION_KEY`)
- **دکمه تلگرام بالا-راست**: موجودی استارز زنده (`payments.getStarsStatus`) + پروفایل + خروج
- دسترسی فقط برای دستگاه مالک (همان گیت اولین کاربر) — api_id/api_hash و نشست‌ها هرگز به کلاینت برنمی‌گردند
- موتور MTProto: **@mtcute/node (لایه ۲۲۳ اسکیمای تلگرام)** — روی سرور یک بار `npm install` لازم است

## تازه‌های نسخه ۲.۱

- **زبان مارکت انگلیسی است** — فارسی از تنظیمات (آیکون چرخ‌دنده) قابل انتخاب است؛ راست‌به‌چپ خودکار
- **گیت API تلگرام فقط برای اولین کاربر**: بار اول که اپ باز شود، فقط به همان دستگاه فرم API ID / API Hash نشان داده می‌شود (اختیاری؛ رد شود دفعه بعد دوباره می‌آید تا کامل کند). بعد از ذخیره دیگر هیچ‌وقت به هیچ‌کس نشان داده نمی‌شود. مقادیر فقط روی بک‌اند (owner.json) ذخیره می‌شوند و به هیچ کلاینتی برنمی‌گردند
- **سبد خرید**: افزودن چند گیفت از بازار → پرداخت پشت‌سرهم با کیف پول → حذف خودکار پس از هر پرداخت موفق
- **تاریخچه**: خریدها/فروش‌ها/استارز/پریمیوم/اجاره‌ها با فیلتر؛ اجاره‌ها مستقیم از API مارکت‌اپ
- **کالکشن‌ها = فقط کف قیمت + چارت**: چارت خط شکسته (خطوط مستقیم) با **لمس** (نمایش مقدار کف و تاریخ) و فیلتر بازه ۱روز/۱هفته/۱ماه/۳ماه/۶ماه/۱سال. آمار مالکان/تعداد ساخت/حجم معاملات حذف شد
- **بخش اجاره کامل شد**: صفحه‌بندی چندمرحله‌ای (تا ۱۶۰۰ گیفت در بار اول) + فیلترهای مارکت‌اپ (کالکشن با کف اجاره، مدل، بک‌گراند، سمبل) + ۷ مرتب‌سازی + نمای شبکه/لیست
- **استارز و پریمیوم در یک صفحه**: سوییچ بالای صفحه، چیپ‌های تعداد استارز، کارت‌های ۳/۶/۱۲ ماهه با قیمت ماهانه، بج «بهترین ارزش»
- **ریسپانسیو**: ۲ ستون موبایل → ۳/۴/۵ ستون تبلت؛ کارت‌های جمع‌وجورتر


## معماری

```
┌──────────────┐      HTTPS       ┌──────────────────────────┐
│  اپ اندروید  │ ───────────────► │  بک‌اند خودت (Node)       │
│  (Flutter)   │                  │  server.js + mtproto.mjs │
└──────────────┘                  └───────────┬──────────────┘
        │                                     │
        │                       ┌─────────────┼───────────────┐
        ▼                       ▼             ▼               ▼
  TON Connect            Marketapp API   TON API      Telegram MTProto
  (خرید/فروش TON)        (اجاره/کالکشن)  (انبار/بیلانس) (@mtcute/node، لایه ۲۲۳)
```

- توکن API و api_id/api_hash **فقط** روی بک‌اند (env یا owner.json) — هرگز در اپ نیست.
- خرید/فروش مارکت تلگرام با **موجودی استارز اکانت خود کاربر** انجام می‌شود (پرداخت واقعی، بدون جعل).
- بخش TON: همه پرداخت‌ها تراکنش واقعی است که کاربر در کیف پول خودش امضا می‌کند.

## قدم ۱ — اجرای بک‌اند (۵ دقیقه)

پوشه `backend/` را روی یکی از این‌ها بگذار:
- **Render.com** (رایگان): New Web Service → Connect ریپو → Runtime: Node → Build: `npm install` → Start: `node server.js`
- Railway / Fly.io / VPS خودت هم می‌شود.

```bash
cd backend
npm install          # @mtcute/node + long (مارکت تلگرام)
cp .env.example .env # بعد مقادیر را پر کن
TG_SESSION_KEY=$(openssl rand -hex 16) >> .env
node server.js
```

متغیرها: `MARKETAPP_API_TOKEN` (اجاره/کالکشن)، `TG_SESSION_KEY` (رمز فایل نشست‌ها — حتماً ست کن)، `OWNER_DEVICE_TOKEN` (فقط اضطراری: انتقال مالکیت)، `TG_OPEN_FOR_ALL=1` (اجازه برای همه دستگاه‌ها).
تست: `https://my-backend.onrender.com/api/health` باید `{"ok":true,"tg_gateway":true,...}` بدهد.

## قدم ۲ — نصب اپ و اتصال

1. اولین اجرا → آدرس بک‌اند را وارد کن → «تست و ادامه»
2. گیت API: API ID / API Hash از my.telegram.org را ذخیره کن (فقط بار اول)
3. آیکون تلگرام بالا-راست → شماره + کد (+ رمز دومرحله‌ای) → وصل
4. تب بازار: کاتالوگ مارکت اصلی تلگرام + فروشندگان دست‌دوم؛ تب انبار: گیفت‌های اکانتت

## قدم ۳ — ساخت APK

سه راه:
1. **GitHub Actions (رایگان، پیشنهادی):** ریپو را push کن → تب Actions → بیلد خودکار → دانلود `gift-market-apk`
2. **Codemagic** رایگان
3. محلی: `flutter build apk --release`

| انبار | گیفت‌های واقعی کیف پول + فروش/تغییر قیمت/لغو فروش + «افزودن گیفت تلگرام» | Marketapp `nfts/owner` یا TON API + `nfts/sale` |
| سبد خرید | چند گیفت → پرداخت پشت‌سرهم با تراکنش واقعی | `nfts/buy` (نیاز به پلن) |
| تاریخچه | رکورد تراکنش‌ها + تاریخچه اجاره API | محلی + `rent/history` (رایگان) |

## نکته مهم درباره پلن API

با توکن فعلی این‌ها **همین الان واقعی کار می‌کنند** (تست زنده شده):
- استارز (قیمت/گیرنده/خرید) ✅
- پریمیوم ۳/۶/۱۲ ماهه (قیمت/گیرنده/خرید) ✅
- کالکشن‌ها + کف قیمت‌ها + مشخصات هر کالکشن (attributes) ✅
- فید اجاره گیفت‌ها + تاریخچه + اجاره من + تمدید/لغو/اجاره‌گذاری ✅
- پرداخت اجاره → **تراکنش واقعی TON** ✅
- فروش/تغییر قیمت/لغو فروش گیفت (تراکنش واقعی) ✅
- انبار از TON API + آیتم‌های کالکشن از toncenter (فال‌بک رایگان) ✅

این‌ها به **پلن API** نیاز دارند (خطای 402، فعال‌سازی در marketapp.org/api-token):
- فید کامل مارکت فروش (`gifts/onsale`) — تا فعال نشود، اپ خودکار فید واقعی اجاره را نشان می‌دهد + بنر شفاف
- خرید NFT (`nfts/buy`) — تا فعال نشود پیام شفاف می‌دهد
- تاریخچه فروش (`gifts/history`)

بعد از فعال‌سازی پلن، **هیچ تغییر کدی لازم نیست** — همه‌چیز خودکار روشن می‌شود.
وضعیت فید فروش را می‌توانی این‌طوری چک کنی:
`GET /api/health` → فیلد `"sale_feed": true` یعنی فید فروش واقعی فعال است.

## نکات فنی

- Flutter 3.24.x — فقط اندروید — minSdk 23
- چارت کف قیمت: CustomPainter اختصاصی (بدون وابستگی جدید) — لمس‌پذیر با خط‌راهنما و برچسب
- تاریخچه کف: `server.js` هر ۱۵ دقیقه از فید کالکشن‌ها اسنپ‌شات واقعی می‌گیرد و در `floor_history.json` (تا ۴۰۰ روز) نگه می‌دارد؛ `/api/floor-history?addr=...&range=1d|1w|1m|3m|6m|1y`
- گیت اولین کاربر: اولین دستگاهی که `/api/owner/status` را صدا بزند «مالک» می‌شود؛ بقیه `locked` می‌گیرند و هرگز فرم را نمی‌بینند
- TON Connect 2.0 با پکیج `darttonconnect_plus` — مانیفست و لیست کیف پول‌ها از بک‌اند خودت سرو می‌شود (`/tonconnect-manifest.json` و `/ton-wallets.json`)
- تراکنش‌ها عیناً همان پاسخ API است که کاربر امضا می‌کند (بدون دستکاری)
- `resolve-gift` لینک `t.me/nft/...` را می‌گیرد و نام/شماره/عکس واقعی را برمی‌گرداند
- نرخ TON/IRT فقط نمایشی است (از صرافی‌های ایرانی)
