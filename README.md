# بازار گیفت تلگرام — نسخه ۲ (کاملاً واقعی، بدون دمو)

اپ اندروید Flutter برای خرید/فروش/اجاره گیفت‌های تلگرام با TON و خرید استارز و پریمیوم.
**هیچ داده دمویی وجود ندارد** — همه‌چیز از API واقعی می‌آید.

## معماری

```
┌──────────────┐      HTTPS       ┌─────────────────────┐      HTTPS      ┌──────────────────┐
│  اپ اندروید  │ ───────────────► │  بک‌اند خودت (Node)  │ ──────────────► │ Marketapp API    │
│  (Flutter)   │                  │  MARKETAPP_API_TOKEN │                 │ + TON API (رایگان)│
└──────────────┘                  └─────────────────────┘                 └──────────────────┘
        │
        └── TON Connect: خرید/فروش با کیف پول خود کاربر (Tonkeeper، Telegram Wallet، …)
```

- توکن API **فقط** در متغیر محیطی `MARKETAPP_API_TOKEN` روی بک‌اند — هرگز در اپ نیست.
- همه پرداخت‌ها تراکنش TON واقعی است که کاربر در کیف پول خودش امضا می‌کند. پرداخت جعل نمی‌شود.
- بدون ثبت‌نام/شماره/یوزرنیم — فقط «اتصال کیف پول» اختیاری (بالا-راست).

## قدم ۱ — اجرای بک‌اند (رایگان، ۵ دقیقه)

پوشه `backend/` را روی یکی از این‌ها بگذار:
- **Render.com** (رایگان): New Web Service → Connect ریپو → Runtime: Node → Build: `(خالی)` → Start: `node server.js`
- Railway / Fly.io / VPS خودت هم می‌شود.

متغیر محیطی را ست کن (راحت‌ترین راه: فایل `backend/.env` که همین الان پر شده — روی سرور کپی شود خودکار خوانده می‌شود):
```
MARKETAPP_API_TOKEN=<توکن خودت>
```

بعد از دیپلوی، آدرس عمومی را داشته باش (مثل `https://my-backend.onrender.com`).
تست: `https://my-backend.onrender.com/api/health` باید `{"ok":true,"token_set":true}` بدهد.

## قدم ۲ — نصب اپ و اتصال

1. اولین اجرا → آدرس بک‌اند را وارد کن → «تست و ادامه»
2. بالا-راست → «اتصال کیف پول» → Tonkeeper / Telegram Wallet / …
3. همه‌چیز فعال است: انبار خودکار پر می‌شود (گیفت‌های واقعی کیف پولت)، می‌توانی بفروشی، استارز و پریمیوم بخری.

## قدم ۳ — ساخت APK

سه راه:
1. **GitHub Actions (رایگان، پیشنهادی):** ریپو را push کن → تب Actions → بیلد خودکار → دانلود `gift-market-apk`
2. **Codemagic** رایگان
3. محلی: `flutter build apk --release`

## بخش‌های اپ

| بخش | توضیح | منبع داده |
|---|---|---|
| بازار | فید گیفت‌ها؛ تب تون (پیش‌فرض) / استارز / همه + جستجو | Marketapp `gifts/onsale` (فروش) + `rent/gifts` (اجاره) |
| کالکشن‌ها | کف قیمت، حجم، مالکان — واقعی | Marketapp `collections/gifts` (رایگان، الان کار می‌کند) |
| جزئیات گیفت | عکس واقعی همان گیفت + مدل/بک‌گراند/سمبل + **آیدی گیفت** + «مشاهده در تلگرام» | تِماداده NFT + تصویر Fragment |
| استارز | تعداد دلخواه + بررسی گیرنده (نام+عکس) + قیمت TON لحظه‌ای + خرید | Marketapp `fragment/stars/*` (رایگان، الان کار می‌کند) |
| پریمیوم | ۳ ماهه/۶ ماهه/یک‌ساله با قیمت واقعی + خرید + لینک `tg://premium_multigift` | Marketapp `fragment/premium/*` (رایگان، الان کار می‌کند) |
| انبار | گیفت‌های واقعی کیف پول + فروش/تغییر قیمت/لغو فروش + «افزودن گیفت تلگرام» با لینک | Marketapp `nfts/owner` یا TON API + `nfts/sale` (رایگان) |
| سفارش‌ها | تاریخچه با وضعیت واقعی تراکنش | محلی (دستگاه خودت) |

## نکته مهم درباره پلن API

با توکن فعلی این‌ها **همین الان واقعی کار می‌کنند** (تست زنده شده):
- استارز (قیمت/گیرنده/خرید) ✅
- پریمیوم ۳/۶/۱۲ ماهه (قیمت/گیرنده/خرید) ✅
- کالکشن‌ها + کف قیمت‌ها + مشخصات هر کالکشن (attributes) ✅
- فید اجاره گیفت‌ها + تاریخچه + اجاره من + تمدید/لغو/اجاره‌گذاری ✅
- پرداخت اجاره → **تراکنش واقعی TON** ✅
- فروش/تغییر قیمت/لغو فروش گیفت (تراکنش واقعی) ✅
- انبار از TON API + آیتم‌های کالکشن از toncenter (فال‌بک رایگان) ✅

این‌ها به **پلن API** نیاز دارند (خطای 402، فعال‌سازی در marketapp.org/api-token):
- فید کامل مارکت فروش (`gifts/onsale`) — تا فعال نشود، اپ خودکار فید واقعی اجاره را نشان می‌دهد + بنر شفاف
- خرید NFT (`nfts/buy`) — تا فعال نشود پیام شفاف می‌دهد
- تاریخچه فروش (`gifts/history`)

بعد از فعال‌سازی پلن، **هیچ تغییر کدی لازم نیست** — همه‌چیز خودکار روشن می‌شود.
وضعیت فید فروش را می‌توانی این‌طوری چک کنی:
`GET /api/health` → فیلد `"sale_feed": true` یعنی فید فروش واقعی فعال است.

## نکات فنی

- Flutter 3.24.x — فقط اندروید — minSdk 23
- TON Connect 2.0 با پکیج `darttonconnect_plus` — مانیفست و لیست کیف پول‌ها از بک‌اند خودت سرو می‌شود (`/tonconnect-manifest.json` و `/ton-wallets.json`)
- تراکنش‌ها عیناً همان پاسخ API است که کاربر امضا می‌کند (بدون دستکاری)
- `resolve-gift` لینک `t.me/nft/...` را می‌گیرد و نام/شماره/عکس واقعی را برمی‌گرداند
- نرخ TON/IRT فقط نمایشی است (از صرافی‌های ایرانی)
